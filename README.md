# AI Student Performance Analyzer

A beginner-level data analysis and visualization project built using Python, Pandas, NumPy, and Matplotlib.

This project collects student performance details, analyzes the data, and generates visual insights using graphs.

---

# Features

- Student data input system
- CSV file creation and storage
- Average, highest, and lowest marks calculation
- Topper identification
- Pass/Fail analysis
- Attendance eligibility checking
- Variance and Standard Deviation calculation
- Student data sorting
- Data visualization using graphs

---
